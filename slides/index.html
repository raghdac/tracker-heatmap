Chapter V · Statistics and settings

The Ranking Is Not Yet Certain

It changes with the settings

With the proposal settings (Table 3.6), DeepSORT is first: 81% of detections score below 0.6, so ByteTrack and BoT-SORT ignore them.

Three videos are too few

Smallest p-value possible with 3 videos: 0.25. Needed: 0.05.

BoT-SORT scores highest, but this is not yet statistically confirmed.

Chapter VI · Conclusions and suggestions

Conclusions, Limits and Next Steps

  1. BoT-SORT tracks best, but only by a little.
  2. Detection is the main problem. In the crowd, only about 1 in 5 people is found.
  3. The tracker changes the heatmap only a little. A bigger image helps about ten times more.

Limits

  • Three videos per scenario
  • No shop video yet
  • One detector, camera view only

Next steps

  • Run the shop test (10+ videos)
  • Repeat the statistical test
  • Try a better detector
